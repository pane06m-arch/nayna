# PAPA QUDI

🌟 **Apple-inspired Glassmorphism Web Portal**

A modern, premium web portal built with pure HTML5, CSS3, and Vanilla JavaScript, featuring macOS-style glassmorphism design and a complete window management system.

## 🎯 Features

- 🎨 **Glassmorphism Design** - Beautiful glass effects inspired by macOS Sonoma/Sequoia
- 🪟 **Window Manager** - Draggable, resizable windows with macOS-style controls
- 🌐 **Multi-language** - Turkish/English support with localStorage persistence
- 🔍 **Spotlight Search** - Apple-style search with Google integration
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- ⚡ **High Performance** - Optimized with lazy loading and debouncing
- 🔒 **Secure** - Input sanitization and XSS protection

## 📦 Modules

- 🌾 **Agriculture & Livestock** - Dashboard with price tracking and analytics
- 📔 **Daily Journal** - Calendar-based journal with auto-save
- 📰 **News Feed** - News cards with RSS/API integration support
- 𝕏 **Twitter/X Automation** - Tweet composer with scheduling
- 📚 **Books & Poetry** - Focus mode editor with statistics
- 🔮 **Fortune Telling** - Interactive card-based fortune system
- 📝 **Homework** - Academic document editor with PDF export

## 🚀 Quick Start

Simply open `index.html` in a modern web browser or visit the [GitHub Pages site](https://pane06m-arch.github.io/nayna/).

No build process or dependencies required!

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern features (backdrop-filter, CSS Grid, Flexbox)
- **Vanilla JavaScript** - No frameworks or libraries
- **SPA Architecture** - Hash-based routing without page reloads

## 🎨 Design System

- **Colors**: Apple Blue (#007AFF), macOS-style gradients
- **Typography**: SF Pro Display, system-ui fallbacks
- **Blur Effects**: backdrop-filter with 25px blur and 180% saturation
- **Animations**: Smooth transitions with cubic-bezier easing
- **Glass Effect**: Transparent backgrounds with border highlights
